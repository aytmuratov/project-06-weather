# Weather Dashboard

A beautiful weather dashboard with mock data. Search by city to view current conditions, hourly forecast, and 5-day forecast.

## Features

- Current weather display with emoji icons
- 5-day forecast cards
- Hourly scrollable forecast
- City search with 7 built-in cities
- Responsive design
- Glassmorphism UI

## Cities Available

New York, London, Tokyo, Paris, Dubai, Sydney, Moscow

## Usage

Open `index.html` in your browser.
